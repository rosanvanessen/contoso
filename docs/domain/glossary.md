# Glossary (English ⇄ Dutch)

| Term | Dutch | Meaning in Contoso |
|---|---|---|
| Member | Deelnemer | Person who builds up pension with the fund |
| Employer | Werkgever | Organisation that employs members and pays contributions |
| Franchise | Franchise | Salary part without accrual (state pension covers it) |
| Pensionable salary | Pensioengevend salaris | Salary on which accrual is based (rule R1) |
| Part-time factor | Deeltijdfactor | 0 < factor ≤ 1; 0.6 = 60 % |
| Accrual | Opbouw | Yearly pension built up (rule R2) |
| Annual statement | Uniform Pensioenoverzicht (UPO-like) | Yearly overview sent to members |
| Value transfer | Waardeoverdracht | Moving accrued rights to another fund |
| Deferred member | Slaper | Left the employer; keeps accrued rights |
| Service request | Klantverzoek | Question/request from a member with an SLA |
